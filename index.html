PDFDTP v1.0

Document Transaction Protocol (PDF)

PDFDTP defines a request/response protocol for transactional document editing, designed for AI agents. Where current tooling answers "ok", a conforming engine answers with a certificate: machine-checkable proof of what the edit did — and the data to undo it. Transport-agnostic: MCP tools/call, stdio, HTTP, or in-process.

Key properties

  • contract — the agent declares what may be touched before the edit
  • certificate — proof that only authorized nodes changed (touched, untouched_changed, render_diff_zones)
  • journal_entry — hash-chained provenance with inverse_ops for audit and rollback
  • strict mode — atomic rollback when verification fails
  • typed issues vocabulary shared with PDFSP
